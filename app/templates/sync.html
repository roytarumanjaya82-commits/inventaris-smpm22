Cara Setup Google Drive

  1. Buka Google Cloud Console.
  2. Buat project baru, aktifkan Google Drive API.
  3. Buat OAuth Client ID tipe Web application.
  4. Tambahkan Authorized redirect URI: http://127.0.0.1:5000/sync/google/callback
  5. Unduh JSON credentials, simpan sebagai credentials/client_secret.json.
  6. Restart aplikasi, lalu klik Login dengan Google Drive.
